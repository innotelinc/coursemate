CourseMate — watch it, listen to it, answer it.

Point it at whatever course you are already taking, on whatever screen you are taking it on. It reads the question, remembers the lecture, and puts a validated answer in front of you — as a card you submit, never as a click it makes for you.

Buy an API key View on GitHub Quick start

A quiz answer has to be right the first time

A vision model returns typed JSON — screen kind, exact stem, options — and the answer is checked against a rubric before it becomes a card.

Every course lives somewhere different

It only sees pixels and audio, so a web LMS, a desktop app, a PDF and a TV behave the same.

Generic assistant prose reads as not yours

A persona file you own, lessons learned from your corrections, and a bounded reflection pass that nudges the voice without letting it wander.

What it does

Watch

Changed frames are classified into a screen kind, a question and its options.

Listen

Chunks are transcribed so the lecture becomes evidence a draft can cite.

Remember

Slides, transcripts and readings become per-course facts and key terms.

Decide

Quiz, test, essay, lecture or reading — routed, drafted, and recorded for review.
